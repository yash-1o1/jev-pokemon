# Emerald catch-all species checklist

Use this community checklist with the RetroAchievements **Gotta Catch 'Em All** progress counter. The achievement page describes the target as obtaining all 212 Pokémon available in Emerald; the list below was linked by a user in that achievement's comments. Its markers are `[!]` for missable and `*` for species available only by breeding, evolution, or in-game trade. Treat it as a route reference and verify progress in RetroArch; the list's `[1]` marker is not explained in its legend. Number 077 is intentionally absent: Roselia is not obtainable in a solo Emerald save.

Run choices: Dark chose **Mudkip**. Follow only the Mudkip → Marshtomp → Swampert starter branch; never select or obtain Treecko or Torchic. For slash-separated alternatives, preserve the run's one-cartridge choices: the list treats Delcatty/Wigglytuff as one missable slot and Latias/Latios as one roaming encounter slot. Emerald has only one guaranteed Moon Stone, so reserve it for the listed Wigglytuff alternative unless the live achievement counter proves another choice is needed. Save before one-time catches and before using limited evolution items. Do not import Pokémon from another save during this achievement run. Keep the chronological missable ledger in view as well.

The RA achievement comments identify species that cannot be caught in a solo Emerald game, including Surskit, Masquerain, Meditite, Medicham, Roselia, Zangoose, and Lunatone. Never import or trade for these as part of this run. Kyogre, Groudon, and Rayquaza are unique captures; save before each battle and confirm capture before leaving.

Source: [RetroAchievements Gotta Catch 'Em All](https://retroachievements.org/achievement/57275) and the checklist linked in its comments.
